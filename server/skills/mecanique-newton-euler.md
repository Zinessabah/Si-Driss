SKILL PÉDAGOGIQUE : MÉCANIQUE DE NEWTON, EULER, ROTATION & OSCILLATEURS (2BAC PC & SM)
- Introduction obligatoire à toute étude dynamique (notation marocaine BIOF avec flèches obligatoires sur tout vecteur) :
  1) Système étudié ; 2) Référentiel terrestre (ou géocentrique/héliocentrique pour Kepler) supposé galiléen ; 3) Bilan des forces avec flèches ($\vec{P}$, $\vec{R}$, $\vec{R}_N$, $\vec{f}$, $\vec{T}$, $\vec{F}_A$) ; 4) Relation vectorielle complète AVANT toute projection ($\sum \vec{F}_{\text{ext}} = m\vec{a}_G$, ex. $\vec{P} + \vec{R} + \vec{f} = m\vec{a}_G$ ou $\vec{P} + \vec{F}_A + \vec{f} = m\vec{a}_G$), suivie de « Par projection sur l'axe... ». Ne jamais utiliser la notation anglo-saxonne sans flèche ($\sum F = ma$ ou $\mathbf{F}$).
- Chute verticale avec frottement fluide ($\vec{P} + \vec{F}_A + \vec{f} = m\vec{a}_G$ avec $\vec{f} = -k v_G^n \vec{k}$) : équation différentielle $\frac{dv}{dt} + B v^n = A$, vitesse limite $v_{\text{lim}} = (A/B)^{1/n}$ (en régime permanent $dv/dt = 0$), temps caractéristique $\tau = v_{\text{lim}}/A$ (si $n=1$). Méthode d'Euler : $a_i = A - B v_i^n$ puis $v_{i+1} = v_i + a_i \cdot \Delta t$.
- Projectiles & Satellites : mouvement circulaire uniforme avec $\vec{a}_n = \frac{v^2}{r}\vec{n}$, troisième loi de Kepler $\frac{T^2}{r^3} = \frac{4\pi^2}{G M}$. Force de Lorentz : $\vec{F}_m = q\vec{v}\wedge\vec{B}$ ne travaille pas ($v = \text{cte}$), trajectoire circulaire de rayon $R = \frac{mv}{|q|B}$.
- Rotation autour d'un axe fixe : RFD $\sum \mathcal{M}_\Delta(\vec{F}_{\text{ext}}) = J_\Delta \ddot{\theta}$, énergie cinétique $E_c = \frac{1}{2}J_\Delta \dot{\theta}^2$, travail $W_{A\to B}(\vec{F}) = \vec{F}\cdot\overrightarrow{AB}$, lien cinématique de non-glissement $a = R\ddot{\theta}$.
- Oscillateurs : ressort ($\vec{P} + \vec{R} + \vec{T} = m\vec{a}_G$ avec $\vec{T} = -kx\vec{i}$), élastique $T_0 = 2\pi\sqrt{m/k}$, torsion $T_0 = 2\pi\sqrt{J_\Delta / C}$, pesant $T_0 = 2\pi\sqrt{J_\Delta / mgd}$ (petites oscillations), conservation de $E_m$ en l'absence de frottement.
